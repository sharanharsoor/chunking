One CLI for files, directories, and N-way

Every command the lab cannot grow into lives here. CLI_REFERENCE.md lists every flag. This page is the set people actually run.

python -m chunking_strategy --help
python -m chunking_strategy --version

Chunk one file

python -m chunking_strategy chunk report.pdf --strategy paragraph_based --format json -o chunks.json
python -m chunking_strategy chunk notes.md -s markdown_chunker

Many files

python -m chunking_strategy batch *.txt --strategy sentence_based --workers 4
python -m chunking_strategy batch-directory ./corpus --strategy auto
python -m chunking_strategy process-directory ./corpus --config config_examples/enhanced_auto_strategy.yaml

See the registry

python -m chunking_strategy list-strategies
python -m chunking_strategy list-strategies --tier lab
python -m chunking_strategy test-strategy sentence_based

N-way and speed

python -m chunking_strategy compare doc.txt -s fixed_size,sentence_based,recursive_character
python -m chunking_strategy benchmark doc.txt --quick
python -m chunking_strategy benchmark doc.txt --custom-algorithms ./my_chunker.py

Full story: N-way compare.

Custom algorithms

python -m chunking_strategy custom load ./my_chunker.py
python -m chunking_strategy custom load-dir ./examples/custom_algorithms
python -m chunking_strategy custom benchmark ./my_chunker.py --compare-with sentence_based

Full story: Bring your own.
